# A refusal is not harmless when the refusal IS the protection

**Context:** CORE-001's fitter shrinks a redaction rectangle so it cannot reach the neighbouring lines. A trim candidate is accepted only if the shrunken rectangle still covers every character of the object being replaced, measured against the redactor's own threshold; otherwise the trim is *refused* and the larger rectangle is kept. The comment written alongside that rule, and the review record that echoed it, said the strictness was free: "being stricter than the redactor costs a refused trim, and a refused trim only leaves the rectangle where it was". The spec had already passed one independent review when a second signer — required because it declared `risk: high` — returned **FAIL** with a reproduction.
**Problem:** leaving the rectangle where it was is exactly the defect the file exists to fix. The trim *is* what keeps the rectangle off the neighbouring lines, so refusing one hands those lines to the redactor. With the leading tighter than the glyph height (12 pt text on 9 pt leading), the target's 16.8 pt glyph box overlaps the next line's box by 7.8 pt: every single trim is accepted and the rectangle is left thin, the next trim is refused for leaving the target under the floor — and the rectangle it keeps still reaches the line below, whose first six characters are then removed and never re-inserted. `keepkeep4` became `p4`. No error, no warning, and the first review had PASSed. Lowering the floor does not rescue it: at the redactor's exact measured transition the trim that would spare the line still leaves 7% of the target's own glyphs, so accepting it would leave the replaced value under its replacement. There is no safe rectangle, only a choice of which failure to have — and the code was choosing silently.
**Solution:** **(1) Ask what a refusal leaves behind, not only what it prevents.** A negative answer from a guard is a decision with an effect: name the effect before calling it safe. Here the guarded action was *the mechanism of safety itself*, so a refusal was the defect wearing the guard's uniform. **(2) When no option satisfies every invariant, fail loudly rather than pick one silently.** The fitter already refused a collapsed rectangle and an unidentifiable target; a refusal that would cost a neighbouring line its characters now raises the same typed error, naming the page, the rect and the line. Refusing a conversion is a visible cost; deleting a line is an invisible one. **(3) Keep the strictness honest by pinning it from above.** A test that only catches the rule being weakened lets the rule be arbitrarily over-strict — mutation-testing the floor to 0.5 left every test green before this round. The floor is now the redactor's *measured* transition (10.0% of the character's box, on both axes, constant across 6/9/12/18/24 pt) plus a small margin, and a boundary row converts the merely-tight case so that over-refusing is a failure too. **(4) A number you rely on, you measure.** The transition was measured for width and assumed for height; the second signer measured the height and found the same 10.0%, which turned an argument into a fact and let a single constant cover both axes.
